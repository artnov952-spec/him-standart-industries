# HIM STANDART INDUSTRIES

[Открыть демонстрационный сайт](https://him-standart-industries-demo.artnov952.chatgpt.site/) · [Публичный репозиторий](https://github.com/artnov952-spec/him-standart-industries)

Демонстрационный B2B-каталог для организаций Узбекистана. Основа оформления ISOMORPH: нейтральный темный первый экран, светлый каталог, один точечный акцент, системная типографика и Lucide SVG. Без стеклянных эффектов, свечения и онлайн-оплаты.

## Возможности

- 50 демонстрационных реактивов с собственными URL, CAS, характеристиками и фасовкой.
- Поиск по словам, синонимам RU/EN, CAS и формулам, с учетом одной опечатки в длинном слове. Многословный запрос уточняет подбор.
- Семь тегов лабораторных задач с кликабельными переходами, фильтры, сортировка, пагинация и восстановление состояния через URL/историю браузера.
- Корзина с атомарным объединением фасовок, сохранением на устройстве и требованиями по каждой строке: чистота, допустимость аналогов и нужный срок.
- Экспорт и проверяемый импорт CSV/TSV для повторной закупки, до 30 строк. Контактные данные в файл не включаются.
- Заявки и отзывы сохраняются в Cloudflare D1. Отзывы ожидают модерации.
- Отдельные отзывы о компании и о каждом продукте.
- Шесть статей, включая контроль воды, агрохимический анализ и буферные системы. Оглавления и переходы к подходящим подборкам.
- Фотографии в единой светлой рамке, без обрезки объекта; нормализация фона документирована в IMAGE-SOURCES.md.
- Контекстный запрос документов, адаптивный просмотр образцов, мобильная версия, HTML-пагинация и обложки для пересылки ссылок.

## Что является демонстрацией

Точный ассортимент клиента, параметры фасовок и квалификации требуется подтвердить. На сайте нет подтвержденных цен и складского наличия. Фотографии взяты из указанных открытых источников; изображение формы вещества или упаковки не является доказательством происхождения продукции. См. IMAGE-SOURCES.md и CONTENT-SOURCES.md.

Макеты документов явно помечены и не подтверждают сертификацию или лицензию. Заявки сохраняются на сервере, но не отправляются менеджеру: Telegram-бот пока не подключен. Контакты взяты из датированной публичной карточки Orginfo и требуют подтверждения.

Демо намеренно закрыто от индексации через meta/X-Robots-Tag. Для реального домена после замены временных материалов нужно обновить SITE_URL/IS_DEMO и снять заголовок noindex в worker/index.ts. Не ставить выдуманные offers, цены 0 или фиктивные оценки в schema.

## Запуск

Node >=22.13.0. Установить зависимости через npm ci, затем npm run dev. Сборка: npm run build. Предпросмотр собранного Worker: npm start.

Схема D1 находится в db/schema.ts, миграции в drizzle/. Локальная база и production независимы. Миграции применяются стандартным процессом Sites, секреты и локальная база не входят в Git.

## Интерактивный первый экран

Графитовая молекулярная скульптура использует отдельный lazy chunk Three.js. Реагирует на указатель и прокрутку, плавно останавливается после изменения позы. Вне первого экрана отрисовка приостанавливается. На мобильном используется легкий параллакс постера; уменьшенное движение и недоступный WebGL имеют запасной режим. Подробности и границы проверки: docs/hero-molecule.md.

## Поиск и области применения

`lib/search.ts` выполняет детерминированный локальный поиск без платного API. Точные CAS и химические формы не подменяются похожими числовыми идентификаторами или сравнительными упоминаниями в описании. Метаданные всех 50 позиций и первичные источники применений находятся в `lib/product-tags.ts`. Теги относятся к задачам лаборатории; они не подтверждают пригодность конкретной квалификации для внесения в почву, применения к человеку или обработки питьевой воды.

## Модерация

API /api/moderate закрыто серверным ADMIN_TOKEN длиной не менее 32 символов. Никогда не помещать этот токен в клиентский код, GitHub, URL или общедоступные файлы. Без серверного секрета модерация закрыта (403). GET возвращает очередь, POST принимает решение по отзыву. Сохраненный новый отзыв не меняет публичный рейтинг до одобрения.

Полные результаты доступных SEO-проверок и ограничения кабинетов описаны в SEO-PRELAUNCH.md. Наличие базовой разметки не гарантирует индексацию, rich snippets или прохождение полевых CWV.
