# Проверка мобильной версии, 29.10.2026

Сохранен выбранный ISOMORPH: темный первый экран, нейтральный каталог, одна семья SVG-иконок. Данные, сервер заявок и правила поиска не менялись.

## Изменения

- У мобильной панели фильтров постоянные верх и кнопка применения, отдельная внутренняя прокрутка и нижний отступ с учетом safe area.
- Категории и строки radio имеют высоту минимум 48 px вместо прежних 20 px у radio-строк.
- Текстовые поля, фасовка, количество и сортировка на мобильном используют 16 px. Физическое поведение iOS Safari с клавиатурой отдельно не подтверждено.
- Публичная ссылка на сайт добавлена в начало README и в поле Website репозитория.

## Локальная браузерная проверка

Проверены главная, каталог, товар «Натрий хлористый», заполненная корзина, статья о спецификации и контакты. Размеры: 320×800, 360×800, 390×800, 430×932, 768×1024, 740×360. Всего 36 состояний: documentWidth совпадает с шириной viewport, проверенные заголовки, текст и элементы управления не выходят за горизонтальные границы. Декоративная молекула намеренно обрезается рамкой первого экрана.

| Сценарий | Результат |
| --- | --- |
| Мобильное меню, переход в каталог | Работает |
| Название, синоним, CAS, формула, задача, пустая выдача | Проверены в UI; результаты соответствуют запросам |
| Категория + задача + квалификация | Семь подходящих позиций, состояние сохраняется в URL |
| Прокрутка фильтров | Внутреннее тело прокручивается, кнопка остается в пределах окна при 360×800 и 740×360 |
| Закрытие панели | Фокус возвращается на кнопку, блокировка прокрутки страницы снимается |
| Тег контроля воды | Две позиции; повторное нажатие снимает тег |
| Сортировка, следующая страница, reload | Сохраняются сортировка, страница и первая позиция |
| Вид списком на 768 px, Back | Список не расширяет страницу, Back восстанавливает сетку |
| Добавление из каталога и товара | Позиции попадают в корзину |
| Фасовка, количество, reload | Выбор сохраняется |
| Объединение одинаковых строк | Две строки 2+1 объединяются в одну с количеством 3 |
| Ограничения количества | 0 приводится к 1, на 999 кнопка увеличения недоступна |
| Очистка и отмена | Отмена сохраняет строки, подтверждение очищает и фокусирует пустое состояние |
| Обязательные поля | Пустая форма останавливает отправку и фокусирует организацию |
| Фотография в корзине | Финальный WebP успешно отображается |

На мобильной главной renderer=poster. В свежем наблюдаемом перечне ресурсов нет модуля сцены Three.js. Реальная прокрутка изменила translateY постера; вне первого экрана состояние стало paused. По исходникам RAF прекращается после затухания и при скрытии страницы. Есть изолированные тесты движения, геометрии и отказа WebGL. Постоянного цикла вращения нет.

22 теста поиска и молекулы, TypeScript и проверка diff прошли. Полная production-сборка и опубликованная версия проверяются при выпуске. Свежие результаты и кадры выпуска сохраняются локально в `outputs/qa/mobile-20261029/`; эта папка исключена из Git.

## Границы проверки

Это браузерная проверка адаптивных размеров на компьютере, не тест физических iPhone/Android. Мобильная клавиатура, системный reduced motion, реальная потеря GPU-контекста, CPU/network throttling и полевые Core Web Vitals не проверялись. Отсутствие видимых ошибок в этих сценариях не является гарантией FPS на всех устройствах.

В этом прогоне не отправлялись реальные заявки/отзывы и не менялись внешние настройки поисковиков/аналитики. Демо сохраняет намеренный noindex. Историческая матрица 35 SEO-проверок с ограничениями доступа остается в [SEO-PRELAUNCH.md](../SEO-PRELAUNCH.md).
