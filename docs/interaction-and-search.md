# HIM STANDART: взаимодействия, поиск и фотографии

Зафиксировано 29.10.2026 для релиза 3. Публичный повтор новой сборки пока не проведен.

## Поиск и идентичность вещества

`lib/search.ts` экспортирует `searchProducts(products, query, { tagIds? })`, `normalizeSearchText` и `parseSearchQuery`. Возвращаются исходные товары по соответствию без изменения данных. Пустой запрос сохраняет входной порядок; каталог без запроса показывает А-Я. Значимые слова соединяются AND. Словарь всех 50 позиций содержит русские/английские синонимы. Нормализация учитывает регистр, русские написания и нижние индексы формул. CAS ищется точно с дефисами, пробелами или только цифрами; формулы и SKU сопоставляются точно. Допускается одна опечатка в словах от 5 символов; короткие идентификаторы и числа не исправляются нечетким поиском.

Безводность, тип гидрата и число молекул воды берутся из названия, aliases и формулы. Сравнение «отличайте от безводного хлорида» в описании не делает гидрат безводным продуктом. Обычные слова применения продолжают искать по description/usage. Моногидрат и 1-водная форма согласуются, несовпадающий гидрат исключается. Регрессии покрывают хлорид железа, сульфат меди, обе формы лимонной кислоты и магний 7-водный/2-водный.

Поиск работает по локальным правилам и словарю. Платные ML/LLM API, внешние поисковые сервисы и передача запросов сторонней модели не используются. Распознавание любого произвольного запроса не обещается.

## Семь тегов

| ID | Подпись | Граница значения |
| --- | --- | --- |
| `analytics` | Аналитика | Лабораторные методики, без медицинского/диагностического допуска |
| `quality-control` | Контроль качества | Подбор по процедуре контроля продукции и сырья |
| `solution-preparation` | Подготовка растворов | Компоненты по методике, без рекомендации концентраций |
| `agrochemistry` | Агрохимический анализ | Анализ почвы и питательных элементов, не внесение удобрений |
| `buffers` | Буферные системы | Компоненты с проверкой формы, чистоты и условий методики |
| `water-treatment` | Контроль воды | Лабораторный контроль воды/водоподготовки, не допуск к обработке питьевой воды |
| `microbiology` | Микробиология | Компоненты сред; квалификацию и партию подтверждают отдельно |

Определения, aliases, полный словарь и первичные ссылки: `lib/product-tags.ts`, экспорт `applicationEvidence`. Для неочевидных применений использованы документы Merck/Sigma-Aldrich, SCP SCIENCE и USDA. Они устанавливают применение соединения, а не соответствие демонстрационной квалификации продукту производителя. Идентичность веществ дополнительно документирована в `EXTRA-PRODUCT-SOURCES.md`.

«Для растений», «для удобрений» и «для почвы» означают подбор для анализа почвы. Набор ограничен хлоридом калия, хлоридом кальция 2-водным и ацетатом аммония. Интерфейс поясняет, что пригодность для внесения/обработки растений не подтверждается. Медицинская лаборатория относится к аналитике с отдельным пояснением; одиночная «медицина» не создает допуск. Одиночная «вода» остается поиском вещества, «для анализа воды» становится контекстом контроля воды. API пересекает несколько тегов по AND; UI хранит один выбранный тег.

## URL, история и взаимодействия

Состояние каталога: `q`, `category`, `grade`, `tag`, `sort`, `view`, `page`. SSR получает все начальные параметры, включая страницу, сортировку и вид. Прямой URL, reload и browser Back восстанавливают состояние. Изменение фильтра сбрасывает страницу. Ввод поиска заменяет запись истории без перехода на каждый символ; переключения фильтров/вида создают запись. Пустая выдача содержит пояснение, сброс и ссылку на запрос спецификации.

Мобильные меню/фильтры поддерживают Escape и возврат фокуса. Sidebar ограничивает прокрутку своей панелью. Подтверждение очистки фокусирует безопасную кнопку, после очистки фокус переходит в пустое состояние. Смена фасовки сохраняет select в фокусе; одинаковые строки объединяются. Количество целое, 1...999, лимит 30 строк явно сообщается. До hydration добавление из карточки товара заблокировано. Заявки сохраняются в демо без онлайн-оплаты и отправки менеджеру/Telegram.

## Фотографии и доказательства

20 презентаций фотографий: 16 обработанных фонов и 4 исходных изображения. Представление: `lib/photo-presentation.ts`; `getProductPhoto` дает единые src/alt для карточки, товара и корзины. Фото показывает вещество, форму или пример упаковки, а не фактический SKU/партию HIM STANDART. Общие иллюстрации сохраняют нейтральные alt и подпись «Не фотография выбранного продукта». Источники и лицензии: `IMAGE-SOURCES.md`.

`outputs/qa/refinement-photo-metadata.json` подтверждает 20 WebP, 1 182 652 байта и сопоставление для 50 товаров. Root отдельно подтвердил успешное декодирование всех файлов (allDecoded=true). Это файловая проверка. Root также проверил открытие/закрытие sidebar с заданными 280/160 ms, Escape, фокус и восстановление body overflow. 24 samples показывают только хвост анимации, не полный видеозамер.

Локально: 12 поисковых тестов, 6 статей, 64 страницы sitemap плюс 16 дополнительных HTML, 23 ресурса, 760 якорей, errors=0 в ограниченном GET-обходе. Браузерный отчет поиска содержит 5 случаев. Interaction audit охватывает выбранные экраны при 360/390/768/1440 px.
